# 🏥 Healthcare Analytics Project | Excel, SQL, Tableau & Power BI

An end-to-end Healthcare Analytics project focused on analyzing patient demographics, doctor statistics, medical visits, diagnoses, laboratory results, and treatment costs using SQL, Microsoft Excel, Tableau, and Power BI.

This project transforms healthcare data into meaningful insights through data analysis, KPI tracking, interactive dashboards, and visual reporting.

## 📌 Project Overview

Healthcare organizations generate large volumes of data related to patients, doctors, medical visits, laboratory investigations, and treatment expenses.

The objective of this project is to analyze healthcare data, identify patterns and trends, monitor key performance indicators (KPIs), and present actionable insights through interactive dashboards.

The project combines SQL-based analysis with Excel, Tableau, and Power BI visualizations to demonstrate practical data analytics and business intelligence skills.

## 🎯 Project Objectives

- Analyze patient and doctor statistics.
- Examine medical visits and diagnosis categories.
- Understand patient demographics and age distribution.
- Analyze laboratory test results and follow-up requirements.
- Monitor treatment costs and healthcare expenditure.
- Identify visit trends across months, years, and geographical regions.
- Develop interactive dashboards for healthcare performance monitoring.
- Support data-driven decision-making through visual analytics.

## 📊 Project Components

### 1. Excel Healthcare Analytics Dashboard

An interactive Excel dashboard presenting healthcare KPIs and analytical visualizations.

**Key features:**
- Total patients, doctors, visits, and laboratory tests
- Average patient age
- Follow-up rate and abnormal laboratory result percentage
- Average workload and treatment cost
- Top diagnosed conditions
- Follow-up requirement distribution
- Laboratory result distribution
- Visits by year
- Treatment cost by type and visit category

**Interactive filters:** Diagnosis, Visit Type, and Visit Year.

### 2. SQL Healthcare Data Analysis

SQL is used to query and analyze healthcare records stored in a relational database.

**Key analytical areas:**
- Retrieving and filtering healthcare records
- Aggregating patient and visit information
- Analyzing laboratory and treatment data
- Calculating summary statistics
- Using SQL queries to investigate healthcare metrics

**SQL script:** `PatientHealthcareAnalytics.sql`

### 3. Tableau Healthcare Dashboard

The project includes the Tableau packaged workbook `HealthcareAnalytics.twbx`.

The Tableau dashboard provides visual exploration of healthcare performance data. The packaged workbook can be opened in Tableau Desktop to inspect its available charts, filters, and dashboard functionality.

### 4. Power BI Healthcare Analytics Dashboard

The project also includes a Power BI dashboard for interactive healthcare reporting and business intelligence.

The Power BI component complements the Excel and Tableau dashboards by providing another environment for exploring healthcare KPIs, patient demographics, visit patterns, and treatment-related metrics.

**Power BI file:** `HealthcareAnalytics.pbix`

## 📈 Key Performance Indicators

The project covers healthcare metrics such as:

| KPI | Description |
|---|---|
| Total Patients | Number of patients represented in the dataset |
| Total Doctors | Number of doctors represented in the dataset |
| Total Visits | Number of recorded healthcare visits |
| Average Age | Average age of patients |
| Follow-up Rate | Percentage of records classified as requiring or having follow-up |
| Total Lab Tests | Number of laboratory test records |
| Abnormal Lab % | Percentage of laboratory results classified as abnormal |
| Average Workload | Average workload according to the defined calculation |
| Average Treatment Cost | Average treatment cost represented in the dataset |

## 🔍 Key Analytical Questions

The dashboards and SQL analysis help investigate:

- Which diagnosis categories are most frequently represented?
- How are patients distributed across gender and age groups?
- Which medical specialties receive the most visits?
- How do visit volumes change over time?
- What proportion of laboratory results are abnormal, normal, or pending?
- How do treatment costs vary across treatment types and visit categories?
- How can healthcare KPIs support operational planning?

## 📊 Key Insights

The dashboards are designed to help identify trends in patient demographics, healthcare visits, laboratory results, and treatment expenditure.

Examples of analytical findings to investigate include specialty-wise visit volumes, age-group distributions, monthly visit patterns, follow-up rates, and differences in treatment costs.

Specific findings should be interpreted from the dashboard values and the underlying dataset.

## 🚀 How to Explore the Project

### Excel
1. Open `HealthcareAnalytics.xlsx` in Microsoft Excel.
2. Navigate to the dashboard worksheet.
3. Explore the KPI cards, charts, and interactive slicers.

### SQL
1. Open `PatientHealthcareAnalytics.sql` in MySQL Workbench.
2. Select the appropriate database schema.
3. Review and execute the queries against the corresponding database.

### Tableau
1. Open `HealthcareAnalytics.twbx` in Tableau Desktop.
2. Load any required data connections.
3. Explore the available charts, dashboards, and filters.

### Power BI
1. Open `HealthcareAnalytics.pbix` in Power BI Desktop.
2. Allow the report to load.
3. Interact with the available visuals and filters.
4. Review the KPIs and dashboard insights.
